# Note Wizard

`omniverse-wizard.html` is a single self-contained page that writes valid Omniverse notes. See [The Note Wizard](../../docs/getting-started/The%20Note%20Wizard.md) for how to use it.

- `wizard.template.html` is the source (edit this).
- `omniverse-wizard.html` is generated by `python3 _rules/tools/build_wizard.py .` (part of `build_all.py`). Do not edit it by hand; CI checks it is current.
- The forms come from `_rules/schemas/`. Change a schema, run `build_all`, and the wizard follows.
