# Submissions

Raw submissions waiting to be turned into notes. The Genesis Table's relay opens a pull request that adds a folder under `genesis/` with the public ledger (`ledger.json`) and a readable copy (`README.md`). Relics and the true Doom are never included.

The validator skips this folder. To process a submission: turn the ledger into a universe (ask Claude, or use the Note Wizard), commit the notes, then delete the submission folder.
