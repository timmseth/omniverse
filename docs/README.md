# Omniverse documentation

Start here. The design document is the repository [README](../README.md); these pages are the practical guides. The whole vault is also browsable as a site at https://timmseth.github.io/omniverse/.

## Getting started
- [For Players](getting-started/For%20Players.md): join a campaign in twenty minutes.
- [For DMs](getting-started/For%20DMs.md): run a dungeon tonight with the DM screen app or Obsidian.
- [For Contributors](getting-started/For%20Contributors.md): add a note, pass the validator, open a pull request.
- [For Universe Builders](getting-started/For%20Universe%20Builders.md): bring your own world and ruleset.
