# Roadmap

What is next, in rough order. The README's section 23 has the milestone definitions; this page is the working list.

## Content
- Tropelandia: a second town per region, ten more dungeons from contributors, the Forgotten Realms-style "serious" neighbour universe fleshed out past its first town.
- More trope packs (horror, heist, political) as modules.
- Rulesets: finish the D&D 5e module's power function and progression; a PbtA-style module.

## Tools
- `replay.py`: rebuild `_state/` from the event log and check it matches (README section 12.2).
- A rumour-board view and a roster view in `_rules/views/`.
- Generated region maps (SVG) from the place tree.
- A static site built by CI from the vault.

## dmScreen
- v1.1: the 3D dollhouse view (roof off, party token, tap a room for its card), full stat blocks and a table roller, town/NPC/faction screens, map export.
- v1.2: run notes synced to a session log draft; a "propose canon" button that writes the session note.

## Process
- A second Omniverse maintainer.
- Playtest reports as a note kind, feeding `status: playtested`.
