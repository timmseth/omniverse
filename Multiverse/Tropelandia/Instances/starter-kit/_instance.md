# Starter Kit

A template instance: copy this folder to `Instances/<your-name>/`, rename the id, and play. It holds everything a new DM needs for three sessions in Barrowdale, starting the day after the Pie Contest Incident.

- [[Session Zero]]: how to start, in twenty minutes.
- [[The Arc]]: three sessions, levels 1 to 3, using [[Ten Rats]], [[The Strike]] and [[The Rent Is Due]].
- Pregens: five characters in `Pregens/`, each with a reason to be in the Gilded Tankard tonight.
- [[Campaign]]: the party, ready to log sessions into `log/`.

Run it from the DM screen app (the three dungeons are in it) or from Obsidian.
